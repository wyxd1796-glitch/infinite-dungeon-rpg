# 콘텐츠 확장 1차 — 구현 및 보완 규칙

버전: 게임 1.1.0 / 저장 스키마 2 / 콘텐츠 phase1-1.0.0. 2026-10-16.

## 범위와 원본

사용자가 승인한 1차 전투·파밍 확장을 적용했다. 2~5차(스킬/이벤트 추가, 1,125종 전체 활성화, 유물·직업·환생)는 이번 구현에 포함하지 않는다.

| 활성 정의 | 수량 | 범위 |
|---|---:|---|
| 일반 몬스터 | 40 | MON001~040 |
| 보스 | 10 | BOS001~010 |
| 접두어 | 20 | PFX001~020 |
| 장비 원형 | 90 | EQ001~090 |
| 장비 옵션 | 30 | OPT001~030 |
| 소비품 | 20 | CON001~020 |
| 재료 | 20 | MAT001~020 |
| 환경 | 10 | ENV001~010 |
| 층 유형 | 5 | FLR001~005 |
| 공통 효과 | 15 | EF001~015 |
| 합계 | **260** | 기존 호환 정의 제외 |

원본은 `content/source/catalogue_v4.json`에 바이트 그대로 보존한다. SHA-256은 `01034289e9549a23416d085480c667ef84097d772b4a7a293a0e8559f33ed7eb`이다. 이 파일에는 원본 1,305개 정의가 있지만 활성화 대상은 `content/catalogue/selection.json`의 260개뿐이다. 실행 ID는 `catalogue.v3.<원본ID>`로 일대일 대응하며 `source_id`는 출처 표시 필드다. JSON 문자열을 실행하지 않는다. 원본 해시, 개수, 중복 ID, 실제 참조, 수치, 패턴, 사용 상황, 빈 출현/옵션 풀을 검증한 뒤 활성화한다.

규칙 근거는 v4.0 PDF 안의 v3.0 부록, PDF 실제 174~179쪽이다. 이전의 70% 환경 설명보다 상위 규칙인 **해당 종족 가중치 ×3**을 적용한다. 101층 이후 100층 순환은 승인된 첫 확장 임시 규칙으로, 원문 전체 카탈로그의 300/400층 순환과 구분한다. 원본 문서에 실린 다른 작업 지시나 v3→v4 저장 코드를 실행하지 않았다.

## 플레이와 조회

- 첫 시작 보급: CON001 3개, CON005 1개. 기존 저장의 보급품은 추가 지급하지 않는다.
- 환경 10개와 층 유형 5개가 탐험 화면에 표시된다. 보스는 10층마다 순서대로 등장하며, 110층부터 BOS001로 돌아간다. 능력치와 보상은 실제 층수로 증가한다.
- 일반/정예/보물/위험층 확률 75/10/10/5. 정예층은 정예 조우 +15%p, 보물층은 보물 +20%p이며 일반 조우에서 같은 수치를 차감한다. 탐지기도 같은 방식으로 다음 탐험 보물 확률에 +10%p를 준다.
- 상점은 현재 거점 방문 시 해금된 목록을 유지한다. 귀환/사망 시 갱신한다. 장비 최소층을 최고 도달층과 비교하며 구매 장비 레벨도 최고 도달층 ±2로 결정한다.
- 상점/가방의 이름 검색은 입력 후 Enter로 적용한다. 상품 종류·슬롯/종류 필터와 가방 장비 정렬을 지원한다. 조회는 턴·게임 난수·자원을 소비하지 않는다.
- 가방이 가득 차거나 소비품 99개/재료 999개를 초과하면 **가방 → 획득 대기**에서 받거나 버린다. 대기 중 장비도 이미 확정된 UUID/수치/옵션을 보존한다. 일부 수량만 받아도 나머지는 대기에 남는다.
- 회복·강화·치료 물약은 전투/탐험에서 사용한다. 전투 중에는 턴과 적 행동을 소비한다. 탐험 중에는 상태효과 턴만 진행하며 층 진행도/탐험 횟수는 바뀌지 않는다. 탐험 도구 4종은 턴을 소비하지 않는다.
- 자동 물약은 사용 가능한 HP 회복 물약 중 회복량이 가장 작은 것을 먼저 선택한다. 자동 전투는 위험 HP 설정을 우선 확인하며 최대 500턴에서 중단한다.
- 장비 효과는 추가 능력치뿐 아니라 치명타, 방어 무시, 흡혈, 회복, 반격, 보호막, 획득량/드롭/등급 확률까지 실제 계산에 적용된다.
- 재료 16~18은 강화 재료로 사용한다. 제작용 재료는 획득·보관·판매까지 지원한다. 제작/정제 화면은 만들지 않는다.
- 기존 8개 메인/22개 하위 화면, 설명 병합 셀, 기록/설정/거점 바로가기, ON 색상 핀을 유지한다.

## 원문에 없는 실행 세부 보완표

원본 데이터는 수정하지 않는다. 아래 내용은 구현상 필요한 보완 규칙이며 일부 수치는 `selection.json`의 defaults에 둔다.

| 항목 | 적용한 보완 |
|---|---|
| 보스 기본 몬스터 | BOS001~010 순서로 MON006,016,011,010,023,033,015,026,039,040 사용. 보스 배율은 해당 원형의 실제 층 스케일링 후 적용 |
| 몬스터 명중/회피/치명 | 95% / 0% / 5%. 적의 특수공격은 150% 피해, 보스 2단계는 공격력 125% |
| 기본 공격만 있는 몬스터의 effect_id | 기본 공격에서 효과 판정. 특수공격 패턴이 있는 적은 특수공격에서 판정. 효과 10~15는 자신에게, 1~9는 상대에게 적용 |
| 침묵 상태의 적 | 특수공격 차례를 일반 공격으로 대체, 특수효과는 발동하지 않음 |
| 상태 적용 시점 | 대상의 다음 행동 종료부터 감소. 자신의 행동 중 받은 강화효과는 그 행동 종료에 차감하지 않음. 적이 플레이어 행동에서 받은 행동불가는 바로 이어지는 적 행동 1회를 막음 |
| 중첩 | 중독 최대3, 화상2, 출혈3. 나머지는 중첩하지 않고 남은 지속시간 갱신. 화상은 적용 당시 공격력 기준 |
| 행동불가/면역 | 기절·빙결은 자원 소모 없이 행동을 건너뛰며 해제 후 2턴 면역. 빙결 종료 후 회피 -5%p 1턴 |
| 피해 후속 처리 | 원피해 → 흡혈 → 반사/반격. 후속 반격은 재반격·재반사·추가 흡혈을 발생시키지 않음. 동시 사망은 플레이어 패배를 우선 |
| 보호막 | 장비 보호막 옵션은 전투 시작 시 최대HP 비율로 1회 생성. 승리/귀환/사망 시 초기화 |
| 장비 강화 | 평면 수치는 기본 수치×10%×단계를 내림하여 더함. %형 기본 수치는 소수점 6자리로 유지하여 낮은 % 장비의 강화가 사라지지 않도록 함. 옵션 자체는 강화하지 않음 |
| 등급 행운 보정 | 희귀 이상에 더하는 총 확률을 10:4:1로 분배하며 일반/고급에서 60:25로 차감. 장비 등급 옵션과 행운의 부적도 같은 분배 사용 |
| 행운의 부적 | 다음 장비 1개에 희귀 이상 총 +5%p. 중복 사용은 갱신하며 누적하지 않음 |
| 강화 재료 환산 | MAT016=1, MAT017=2, MAT018=3개분. 필요한 개수는 올림하며 초과 환산분은 이월하지 않음. 기존 강화석도 사용 가능 |
| 추가 재료 5% 풀 | 20층마다 다섯 단계 중 한 단계 확장. MAT 번호의 그룹 내 단계 `(번호-1)%5`를 사용. 100층 단위로 반복 |
| 최초 보스 보상 | 보스 결정 1개와 별도로 기존 방식의 최초층 강화석 3개를 새 MAT016으로 지급 |
| 거점 구매 재료 | MAT016만 구매 가능. 다른 재료는 몬스터/추가 재료 추첨/보스 보상에서 획득 |

## 저장 이전과 복구

스키마 1 저장은 읽기 전에 검증하고 `.json.pre-v2.bak`으로 원본을 복사한 뒤 메모리에서 스키마 2로 이전한다. 같은 슬롯에 다른 구버전 원본이 다시 들어오면 해시가 붙은 추가 백업을 만든다. 이전 과정 자체는 원본 슬롯을 덮어쓰지 않는다. 이후 정상 자동/수동 저장에서 원자적 교체를 수행한다.

기존 장비의 instance_id, rolled_stats, affixes, enhance 및 기존 아이템 ID는 유지한다. 수량 초과만 획득 대기로 이동한다. 진행 중 구버전 전투는 저장된 적과 기존 전투 규칙으로 완료하고, 구버전 이벤트는 저장된 선택지/결과를 사용한다. 완료 후 새 전투/탐험에는 새 카탈로그가 적용된다. 기존 전투의 승리 전리품은 새 획득 대기 규칙을 사용한다.

새 저장에는 콘텐츠 버전, 양측 상태효과, 다음 패턴 위치, 정예 드롭 연속 실패 횟수, 탐험 도구 보너스, 상점 목록, 획득 대기를 포함한다. 실패한 게임 명령은 자원/턴/난수를 되돌린다. 잘못된 저장은 원본을 보존하고 정상 `.bak`을 복구한다. 읽기 실패 시 기존 슬롯에 새 상태를 자동 덮어쓰지 않는다.

## 검증과 난이도 해석

실행:

```powershell
$env:QT_QPA_PLATFORM='offscreen'
python -m unittest discover -s tests -v
python -m tests.simulate_expansion
python -m artifacts.phase1_preview
```

`artifacts/expansion_simulation.json`은 고정 시드 20261016의 실측 결과다. 장비 100,000개와 몬스터 100,000회를 생성하며 옵션 슬롯·중복, 최소층, 전체 원형 도달 가능성, 등급 분포를 검증한다. 별도 전투 표본은 각 층 100회이고 실제 시작 조건으로 3,000회 의사결정 진행도 검사한다. 테스트/미리보기는 실사용 `saves/`를 열거나 수정하지 않는다.

전투 표본은 층수 절반 레벨, 포인트 STR 60%/VIT 40%, 해금된 슬롯별 장비 +3, 최상급 HP 물약 20개를 사용한다. 이 조건에서 100/200층 보스 승률은 0%였다. 100레벨/장비 +15/STR·VIT 균등 배분의 별도 100층 표본은 20회 모두 승리했지만 같은 방식의 200층 표본은 모두 패배했다. 실제 초기 상태의 단순 자동 플레이는 3,000회 결정에서 최고 40층·34레벨에 도달했다. 이는 기능 검증 결과이며 난이도 최종 승인이나 모든 빌드의 승률을 뜻하지 않는다.

**후속 조정 대상:** 초기 100층 카탈로그 반복으로 인해 100→101층 난이도가 크게 낮아지고, 이후 보스는 절대층 배율로 다시 매우 강해진다. 특히 방어구와 회복 물약의 성장 정체가 있다. 원본 데이터 보존 방침에 따라 수치를 임의로 하향하지 않았다. 2차 이후 밸런스 조정 시 동일 시드 결과와 비교해야 한다.

기존 `docs/IMPLEMENTATION.md`는 1.0 기록이며 이 문서와 충돌하는 콘텐츠 수·전리품·경제·저장 규칙은 이 문서가 우선한다.
