# 03-02 — 명시적 활성 목록과 지역 선택

2026-10-18 완료. 게임 1.2.0 / 저장 스키마 3 유지.

## 실행 계약

- `content/catalogue/selection.json`의 `selection_schema: 2`, `active_ids`가 종류별 활성 ID와 순서를 지정한다. 개수로 원본의 앞 N개를 선택하지 않는다. 현재 260개와 순서를 그대로 옮겼다.
- 어댑터의 지원 범위는 활성 목록과 별개다. 원본에 존재해도 아직 구현하지 않은 EF016~040, OPT031 이후 등은 선택할 수 없다. 지원 범위를 늘릴 때는 효과 구현과 검증이 선행되어야 한다.
- 원본은 ID로 조회한다. 원본 행 순서는 추첨 순서를 바꾸지 않는다. 활성 목록과 지역 풀의 순서는 가중 추첨의 재현성에 영향을 주므로 의도 없이 정렬하지 않는다.
- 보스 원형은 보스 ID→몬스터 ID 사전으로 연결한다. 배열 위치나 보스 번호에 의존하지 않는다.
- `content/catalogue/regions.json`은 10개 지역의 층 범위, 환경 ID, 보스 ID, 순서가 있는 몬스터 풀을 지정한다. 풀 안에서는 원형의 최소·최대 층 조건을 추가 적용한다.
- 현재 반복 구간 100층, 보스 간격 10층, 주 계열 가중치 3을 데이터로 보존한다. 비보스 층에서 직접 보스전을 시작하는 기존 API도 이전 보스 구간을 선택하는 동작을 유지한다.
- 장비·재료 드롭 및 층별 성장 수식은 기존 규칙을 사용한다. 100→101층 난이도 문제는 해결하지 않았으며 후속 고층 확장 과제다.
- 옵션 슬롯은 `·`와 쉼표를 모두 허용하고 공백을 제거한다. `전체`·`방어구`를 명시적인 슬롯으로 변환하고 알 수 없는 슬롯은 거절한다.
- phase2 아이템 참조 검증도 활성 ID 목록을 사용한다. 승인된 스킬 8개·이벤트 20개는 유지한다.

## 로딩 거절 조건

활성 목록의 종류 누락·중복 ID·다른 종류의 ID·원본 부재·미지원 실행 정의, 보스 원형 연결 오류, 미지원 패턴·옵션 단위·슬롯을 거절한다. 지역은 ID 중복, 층 범위 누락/겹침, 비활성 참조, 빈 층별 출현 풀, 잘못된 반복 구간·보스 간격·계열 가중치를 거절한다. 선택 파일만 편집해서 미구현 콘텐츠를 활성화할 수 없다.

## 저장·화면·보유 목록

추가 저장 필드나 저장 이전은 없다. 진행 중 적·장비·이벤트 결과·획득 대기를 재생성하지 않는다. 화면 진입 경로·비용·해금·보상·행동 소모는 변경하지 않았다. 보유 아이템/학습한 스킬만 사용 목록에 표시하는 기존 정책을 유지한다.

## 검증 결과

- `.venv/Scripts/python.exe -m unittest discover -s tests`: 기존 120개 통과(44.023초).
- `.venv/Scripts/python.exe -m unittest tests.test_selection -v`: 추가 8개 통과(3.102초). 위 실행과 합쳐 서로 다른 테스트 128개 통과이며, 128개를 한 번에 실행한 기록은 아니다.
- 변경 전 시드 7, 713, 20261018 × 1~300층 × 일반/정예/보스 = 2,700건을 기록했다. 환경, 생성된 적 전체, 장비 전체, 난수 상태를 직렬화한 SHA-256이 변경 후와 동일하다.
- 비교 해시: `d18baa72ad456c299db4198179ccb973acfddb1d5e1d64d9af17a405646e375b`. 재현 코드는 `tests/test_selection.py`의 `selection_digest`에 보존했다.
- 원본 행 순서 반전 시 실행 정의·출현 풀 유지, 활성 순서 변경 반영, 잘못된 참조/범위/패턴/슬롯 거절, 전투·획득 대기 복원 보존을 검사했다. 기존 저장 이전·이벤트 결과·가방 초과 검사는 120개 회귀에 포함된다.
- 원본 카탈로그 SHA-256 유지: `01034289e9549a23416d085480c667ef84097d772b4a7a293a0e8559f33ed7eb`.
- 실행 배치 파일과 UI는 수정하지 않았다. 실제 Windows 표시 검수와 고층 밸런스 검증은 별도 잔여 과제이며, 이번 단계에서 완료로 판정하지 않는다.
