# 03-04/03-05 — 공통 효과 구현 기록

2026-10-18. 설계 계약은 [EFFECT_TIMING.md](EFFECT_TIMING.md)를 따른다. 원본 카탈로그는 수정하지 않고 명시적 실행 정의를 `core/phase3_effects.py`에 둔다.

## 03-04 완료

EF016~025의 지속 피해·명중/회피·무장 해제·혼란·취약, 최대 중첩과 갱신, 대상 행동 기준 기간을 구현했다. 해독 물약은 독성 폭발을, 만능 치료제는 신규 디버프를 제거한다. 응급 치료의 기존 제거 범위는 유지한다. 플레이어와 적 모두 같은 처리 경로를 사용한다.

혼란은 유효 행동에서만 25%를 추첨하고 기절/빙결이 있으면 추첨하지 않는다. 취소한 행동은 자원·스킬 신규 대기시간·사용 횟수를 소비하지 않고, 기존 대기시간·상태 기간은 진행한다. 행동의 실제 실행 여부를 반환하여 자동/수동 스킬 처리에 공유한다.

첫 신규 전투는 `battle_rules_version=2`를 사용하며 이전 전투는 버전 필드가 없어도 1로 취급한다. EF016~025 상태에는 `runtime_version=2`, `source_side`, `source_atk`, `eligible_turn`을 저장한다. 이전 전투에 신규 효과를 추가하지 않고 종료 후 새 전투부터 적용한다. 저장 스키마 3에 추가하는 선택 필드이며 새 스키마 이전/원본 덮어쓰기는 없다. 후속 03-05에서 버전 3을 추가한다.

신규 효과가 없던 기존 전투 51행동 비교는 추가 메타데이터 `battle_rules_version`만 제외하고 기존 기준 해시를 유지했다. 출현·장비 2,700건 비교도 유지했다. 기존과 신규를 합친 156개 테스트가 27.854초에 통과했다. 상태 설명을 줄바꿈으로 바꾼 뒤 UI 21개도 3.961초에 통과했다(중복 포함 별도 실행).

현재 단계는 **효과 처리 기반 연결**이다. 새 고층 몬스터/장비/소비품의 자연 획득·조우 경로를 앞당겨 추가하지 않는다. 기존 스킬을 바꾸거나 신규 효과를 임의로 부여하지 않는다. 해당 공급 콘텐츠의 연결은 03-06 이후 담당 작업에서 검증한다.

## 03-05 완료

EF026~040의 MP 비용 증가·최대 MP 감소·공격 스킬 배율·치명·피해 감소·방어력·회복·MP 흡수·보호 결계·반격·생존·보상 강화를 구현했다. 활성 효과는 총 40개, 활성 카탈로그는 285개다. 원본 출처 연결은 phase2 28개를 합쳐 313개이며 미연결 원본은 992개다. 몬스터 40종·보스 10종·장비 90종 등 기존 출현 범위는 그대로다.

- `skill_mp_cost`가 올림한 실제 비용을 사용 판정·MP 예약·자동 선택·실제 소비·전투/스킬 화면에 공유한다.
- 최대 MP 감소는 부여 즉시 현재 MP를 상한으로 자른다. 갱신 시 중복 감소하지 않고 제거/만료/불러오기 시 현재 MP를 채우지 않는다.
- 일반·강공격과 공격 스킬 배율을 분리하며 회복 스킬 배율은 바꾸지 않는다. 치명/일반 감소/반격은 기존 상한을 사용한다. 철벽은 별도 감소 배율을 유지한다.
- 급속 치유는 부여 턴을 제외하고 다음 대상 턴 시작부터 발동한다. 마나 흡수는 실제 1차 직접 HP 피해의 5%를 자기 MP로 회복하며 보호막 피해·과잉 피해·반격에는 적용하지 않는다. MP 필드가 없는 적에게 새 MP 자원을 생성하지 않는다.
- 보호 결계는 최초 직접/반격 피해에서 한 번만 발동한다. 기존 보호막과 최댓값을 사용하고 같은 상태 갱신/저장 복원으로 발동 여부를 초기화하지 않는다. 상태가 끝나도 이미 생성한 보호막은 남으며, 이후 별도 재부여된 상태만 다시 발동할 수 있다.
- 최후의 저항은 대상별·전투당 한 번만 발동한다. 보호막 후 치명 피해를 판정하고 최대 HP 1%(최소 1)로 생존하되, 생존 HP는 피격 전 현재 HP를 넘지 않도록 해 회복 효과가 되지 않게 한다. 직접/반격/지속/반사에 모두 적용한다. 제거·재부여·저장 복원으로 사용 기록을 되돌리지 않는다.
- 행운/황금 축복은 큰 값 하나를 선택해 기존 골드 보너스에 더하고 총 +200% 상한을 적용한다. 플레이어의 전투 승리에서 한 번만 계산하며 이벤트·판매·획득 대기 수령에는 다시 적용하지 않는다.
- 만능 치료제는 EF016~028만 추가 해제한다. 신규 강화 EF029~040과 기존 긍정 효과는 유지한다.
- 플레이어/적 상태 설명을 줄바꿈으로 표시하고, 보호 결계의 `[발동 완료]`·최후의 저항의 `[사용 완료]`를 표시한다. 내부 연산자명 대신 실행 효과 설명을 표시한다. 보유 목록 정책은 유지한다.

## 저장 호환과 적용 시점

게임/저장 스키마는 1.2.0/3을 유지한다. 신규 전투의 `battle_rules_version`은 3이다. 버전 없음/1은 기존 전투, 2는 EF016~025까지, 3은 EF016~040까지 허용한다. 이전 전투는 불러오면서 규칙 버전을 올리지 않으며 다음 전투에서만 3으로 시작한다.

EF016~025의 `runtime_version`은 2, EF026~040은 3이다. EF037은 상태에 `triggered: bool`을 추가한다. 전투 버전 3에는 `effect_combat_state.player.survive_used`와 `.enemy.survive_used`가 필요하다. 생존 플래그는 상태 인스턴스 밖에 보존하고 새 전투 시작에서만 초기화한다. 원본 출처·기간·스택·시점·유한 공격력 스냅샷·버전/발동 플래그를 저장 로딩 단계에서 검사한다.

저장은 `execute` 완료 후에만 수행한다. 테스트에서 직접 부여/타격 보조 함수를 호출한 중간 상태는 저장 경계가 아니며, 명령 완료 시 난수 상태가 확정된다. 기존 버전 프로그램은 새로운 상태 ID를 알지 못하므로 신규 효과를 가진 저장의 구버전 역호환을 주장하지 않는다. 기존 저장을 읽는 정방향 호환과 이전 전투 보존을 검증했다. 실사용 저장은 수정하지 않았다.
