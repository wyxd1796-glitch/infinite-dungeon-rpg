## 적용 규칙

- 환경은 10층 단위로 300층마다, 몬스터·보스는 400층마다 독립 순환한다. 1~1200층의 모든 경계와 조합에서 출현 풀이 비지 않는지 검사했다.
- 1~100층은 환경 위험%를 적 HP·공격력에, 보상%를 전투 골드·경험치에 적용한다. 주 종족 가중치는 ×3이다.
- 101층부터 환경 원본 위험/보상%를 다시 곱하지 않는다. 기존 절대층 성장과 전투 보상 ×1.27을 유지한다. 주 종족/기타 70:30, 한쪽 풀이 없으면 원본 가중치로 선택한다.
- 고층 환경 효과는 새 전투 시작 시 기본 10%로 1회 시도한다. EF016~028은 플레이어 약화, EF029~040은 적 강화다. 대상의 저항·효과 지속시간은 공통 효과 규칙을 따른다. 불러오기로 다시 적용하지 않는다.
- 기존 전투는 저장된 환경 스냅샷을 우선한다. 고층 버전이 없는 이전 전투는 기존 100층 환경 규칙을 유지한다. 조회·안내는 턴과 난수를 사용하지 않는다.
- event_tags, environment_tag, on_enter_text 및 원본 순환/종족 규칙 문구는 출처 메타데이터다. 현재 이벤트 풀은 기존 eligible 조건을 사용하며 환경 태그에 따른 추가 제한을 만들지 않는다.
- 보물 층은 보물 조우 확률을 올린다. 위험 층 골드 보정은 전투 보상에만 적용하며 보물 상자 골드·경험치에 적용하지 않는다.
