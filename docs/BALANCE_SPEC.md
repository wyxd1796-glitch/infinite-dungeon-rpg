# 밸런스 기준과 자동 전투 정책 — 1.2.0-policy1

2026-10-17. 로드맵 2단계 구현·평가 명세. 게임 버전 1.2.0 및 저장 스키마 3을 유지하며 선택 설정 두 필드만 추가한다. 고층 출현·장비·적 수치는 변경하지 않는다.

## 설정과 호환

버전별 정의: `content/balance_profiles/1.2.0-policy1.json`. 기존 balance.json의 모든 설정을 전투·성장·경제·드롭·자동 사용의 `values`로 분리하여 로더에 연결했다. 키 누락·중복·초과는 거절한다. 전투 상한, 성장 포인트, 카탈로그 장비 드롭 확률, 자동 설정 기본값도 버전 정의를 읽는다. 원본 base/balance.json은 보존하며 프로필 없는 독립 콘텐츠 테스트의 호환 경로로만 사용한다. 피해 계산식 자체와 콘텐츠별 수치는 기존 실행 원본에 남는다.

| 설정 | 범위 | 이전 저장/새 게임 기본값 |
|---|---|---|
| recovery_policy | potion_first / skill_first / efficient | potion_first |
| mp_reserve | 정수 0~999 | 0 |

기존 스키마 1→2→3 이전 절차와 백업은 유지한다. 스키마 3의 누락 필드는 엔진 로딩 시 기본값만 추가하며 자원·장비·스킬을 재계산하거나 초기화하지 않는다. 잘못된 정책·음수·실수·불리언 예약량은 명령과 스키마 3 저장 검증에서 거절한다. 명령 실패는 상태와 난수를 원복한다.

설정 → 게임 설정 → 자동 전투에서 정책과 `공격 후 남길 MP`를 변경한다. 전투 화면과 설정 화면의 `다음 자동 행동`은 실행과 같은 `next_auto_action()` 판정을 읽으며 턴·난수·자원을 소비하지 않는다. 실제로 실행할 때 다시 판정하므로 그 사이 HP나 상태가 바뀌면 결과도 바뀐다.

## 행동 선택 계약

1. 전투가 아니거나 결과 확인 대기면 중단한다.
2. 위험 중단이 켜져 있고 HP 비율이 기준 **이하**이면 어떤 회복보다 먼저 중단한다.
3. 자동 물약·자동 스킬 스위치와 개별 스킬 설정을 존중한다. 아이템은 보유 수량 1 이상, 스킬은 학습·해금·MP·침묵·쿨다운·이전 버전 전투 조건을 공통 함수로 검사한다.
4. 물약 우선: 기존의 HP 기준과 가장 작은 HP 물약 선택을 유지한다. 물약이 없으면 기존 전체 스킬 우선순위로 넘어간다. 기존 저장의 행동을 유지하기 위해 이 모드에서 회복 스킬을 공격 스킬보다 강제로 앞세우지 않는다.
5. 회복 스킬 우선: 사용 가능한 회복 스킬 중 우선순위·ID 순으로 고르고, 없으면 기존 물약 기준을 적용한다.
6. 효율 우선: 사용 가능한 정화 스킬과 제거 가능한 상태이상이 있으면 정화를 우선한다. 그 외에는 부족 HP로 제한한 실제 회복량이 큰 수단을 고른다. 같은 회복량이면 MP를 사용하는 스킬 우선, 스킬끼리는 우선순위·ID, 물약끼리는 ID 순이다. 0 회복 후보는 제외한다. 사용량/가격으로 나눈 비율 최적화는 아니다.
7. 회복 스킬 자체의 HP 조건(기존 회복 70% 이하, 응급 치료 50% 이하 또는 제거 가능 상태)과 물약의 기존 사용 기준을 유지한다. 효율 정책이 이 조건을 우회하지 않는다.
8. 일반 스킬은 우선순위 1~9, 동순위 ID 순이다. `damage`와 `tactical_damage` 공격 스킬은 사용 후 MP가 예약량 이상이어야 한다. 회복·버프·보호막과 수동 사용에는 예약량을 적용하지 않는다.
9. 후보가 없으면 일반 공격, 전투 종료 또는 위험 중단까지 반복한다. 기존 500행동 안전 한도를 유지한다. 행동불가·지속 피해의 턴 소비는 기존 전투 실행기가 담당한다.

보유 목록 정책은 [OWNED_LISTS.md](OWNED_LISTS.md)를 따른다. 미학습 스킬은 자동 후보가 되지 않으며, 부족 MP/쿨다운인 배운 스킬은 UI에 사유와 함께 남는다.

## 능력치와 피해 순서

기본 능력치 → 장비의 능력치 보너스 → 행운 비율 → 공격/방어/HP/MP 기본 산식과 장비 직접 수치 → 학습한 패시브 → 상태효과 → 상한 및 정수화 → 전투의 함성/철벽 방어 순서다. 신규 직업 계수는 아직 없다. 추가할 때 기존 장비 굴림을 변경하지 않고 명시적으로 합성 위치를 설계한다.

치명 75%, 회피 45%, 반격 40%, 일반 피해 감소 70%, 흡혈 25%, 상태 저항 75%, 추가 골드/경험치 200% 상한을 유지한다. 기존 전투 호환 경로는 원래 계산을 사용한다. `content/base/balance.json`의 과거 회피 75% 필드를 현재 카탈로그 전투 상한으로 오해하지 않는다.

직접 피해는 명중 판정 → 공격 배율·일반/강공격 보너스·0.9~1.1 변동에서 방어력×0.6×남은 방어율 차감 및 내림(최소 1) → 치명·추가 피해·일반 피해 감소 곱 후 내림 → 철벽 별도 감소 후 내림 → 방어 행동 50% 후 내림 → 탐험 보호 30% 감소 후 내림 → 최소 1 → 보호막 차감 → 남은 HP 한도로 실제 피해 확정 순이다. 이후 실제 피해 기준 흡혈과 기존 반사·반격 규칙을 적용한다. 2차 피해는 재귀 반사·반격·흡혈을 만들지 않는다.

## 목표와 평가 전제

목표는 일반전 P50 2~5행동, 정예 4~9, 보스 8~18, 준비된 보스 승률 60~85%, 같은 준비의 빌드 승률 차이 15%p 이내다. 일반층 경계 20% 이내 변화, 보급 간격 3~8층, 10층 구간에 의미 있는 장비 갱신 1회 이상은 장기 진행 평가 목표이며 단기 표본으로 확정하지 않는다.

| 표본 | 준비/예산 | 용도와 제한 |
|---|---|---|
| 통제 전투 | 30층, 레벨 30, 획득 가능한 능력치 87·스킬 6포인트, STR/VIT 52/35, 해당 층 해금 장비 7부위 +3, CON002 5개, 예약 MP 16 | 같은 시드의 장비·적을 공유하는 정책 비교. 장비/강화 비용을 실제로 벌었다는 검증은 아니므로 자연 진행 난이도 승인 자료와 구분 |
| 자연 진행 | 신규 캐릭터의 초기 재화·물약, 실제 획득 보상으로 구매/강화/회복, 100결정×20시드 | 초기 경제·귀환·사망·드롭 관찰. 20레벨 이후 회복 빌드나 장기 갱신 주기 확정에 부족 |

전투는 3빌드×3정책×3적 종류×200회=5,400회, 각 조합은 20시드×10회다. 진행은 3빌드×3정책×20시드×100결정=18,000결정이다. 비교용 전투에서는 위험 중단을 끄고, 진행에서는 기존 위험 관리 정책을 사용한다. 기존 3,000결정 평가 도구도 기본 인수를 유지한다.

기록: 승률, 전투 P50/P90, 물약 소비, MP 감소량, 스킬 사용, 중단, 진행별 귀환·현재 골드 순증감·장비 드롭·사망층. MP 지표는 행동 전후의 양수 감소량이며 동일 행동의 MP 재생이 있으면 총 지출보다 작을 수 있다. 골드 순증감은 시작 200G 대비 잔액이며 보유 장비의 평가액을 포함하지 않는다.

재현: `.\.venv\Scripts\python.exe -m tests.simulate_auto_policy`. 원자료는 `artifacts/auto_policy_simulation.json`, 해석은 `docs/AUTO_POLICY_REPORT.md`에 기록한다. 초기 표본의 목표 미달 때문에 적 수치를 일괄 하향하지 않는다. 통제 준비와 자연 성장의 차이를 먼저 분리하고 이후 단계의 장비·고층 성장 설계에 사용한다.

## 구현 검증과 남은 승인

전체 회귀 114개 통과(31.254초). MP 예약 안내 문구 보완 후 정책 전용 9개 테스트도 재통과했다. 기존 자동 루프와 기본값의 20시드 결과·난수 일치, 회복 우선순위·유효 회복 동률·정화·침묵·MP 부족·쿨다운·행동불가·위험 경계·저장 왕복·설정 거절·프로필 값 보존을 검사했다. 268×861 및 250×400에서 정책 선택과 미리보기가 가로 넘침 없이 표시되고 조회 시 상태·난수가 바뀌지 않는 것도 검사했다.

02-01~10은 구현과 측정 근거를 확보했다. 02-11의 추가 근거는 [장기 측정](LONG_TERM_REPORT.md)과 [수치 결정](BALANCE_DECISION.md)에 기록한다. 통제 표본의 보스 승률 100%를 밸런스 승인으로 사용하지 않는다. 1단계 실제 Windows 배율·다중 모니터 수동 검수는 별도로 남는다.

장기 후속 검증: 240회 실행·720,000결정 및 회귀 117개를 검증했다. 기존 수치 유지와 미달 과제의 3단계 연계를 확정하여 02-11을 완료했다. 초기 100결정 표본의 한계를 장기 자료로 보완하되, 실제 사용자 플레이와 자동 운용의 차이는 보고서에 남겼다.
