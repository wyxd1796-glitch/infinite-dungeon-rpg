# 보유 항목 표시 정책 및 검수

2026-10-17. 다음 개발 단계에 앞서 사용자가 요청한 보유 목록 점검과 수정.

| 화면 | 점검 결과 / 적용 |
|---|---|
| 던전 물약 | 기존 수량 1 이상·전투 사용 가능 종류 필터 유지 |
| 던전 스킬 | 미학습까지 나오던 목록을 학습 레벨 1 이상으로 수정 |
| 가방 소비품 | 기존 보유 필터 유지 |
| 가방 재료 | 수량 0 항목을 제외하도록 수정 |
| 장비·강화 대상·창고 | 기존 가방/착용/보관 인스턴스 참조 방식 유지 |
| 강화 재료 | 보유 수량 1 이상만 표시, 없으면 안내 |
| 스킬 액티브·패시브 | 기본 `배운 스킬`, 별도 `새 스킬 학습` 보기 제공 |
| 스킬 자동 설정 | 배운 액티브에만 표시 |
| 상점·학습·이벤트 선택 안내 | 구매·학습·선택 경로 유지. 미보유 비용은 부족 사유 표시 |
| 획득 대기 | 이미 발생한 미수령 보상만 표시하는 기존 처리 유지 |

보유했지만 현재 MP·턴·장소·필요 수량 조건이 부족한 대상은 숨기지 않는다. 사용 가능 조건과 보유 여부는 별개다. 필터·빈 목록·선택 갱신은 화면 처리이며 게임 수치와 저장 스키마는 바꾸지 않는다.

`tests/test_ui.py`에 보유 소비품/재료, 마지막 수량 제거, 강화 재료 빈 목록, 학습 전후/재분배 목록, 액티브·패시브 빈 목록, 미학습 자동 설정 숨김, 전투 목록의 MP 부족 보유 스킬 유지 검사를 추가했다. 기존 잠금·좁은 창 검사는 학습 보기로 이동했다. `tests/preview_phase2.py`도 학습 보기에서 미학습 스킬을 캡처한다.

검증 명령: `.\.venv\Scripts\python.exe -m unittest discover -s tests -q` (`QT_QPA_PLATFORM=offscreen`). 실제 Windows 표시·다중 모니터 수동 검수의 남은 상태는 변경하지 않는다.

최종 결과: 전체 104개 테스트 통과(15.764초), `git diff --check` 통과. 최초 추가 테스트에서 같은 탭으로 이동할 때 화면 갱신을 생략한 테스트 구성 오류가 있어 명시적으로 갱신한 뒤 전체를 다시 실행했다. 실사용 저장 및 게임 수치는 변경하지 않았다.
