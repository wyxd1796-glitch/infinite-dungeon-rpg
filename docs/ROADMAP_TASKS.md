# INFINITE 전체 개발 실행 체크리스트

작성일: 2026-10-17 · 기준: [전체 상세 기획서](MASTER_ROADMAP.md) · 콘텐츠 항목: [전체 대장](CONTENT_INVENTORY.md)

아래 항목은 앞으로 수행할 작업이다. 1.2.0 구현과 기존 검증이 끝났더라도 향후 단계의 검수까지 완료한 것으로 표시하지 않는다. 체크는 산출물과 검증 근거가 있을 때만 바꾼다. 담당자·완료 커밋·결과 문서 링크는 각 행의 마지막 칸에 기록한다.

총 137개 항목: 로컬 개발·검수 136개와 별도 요청에 따른 원격 게시 1개. 상태 표기: `미착수` → `진행` → `검증` → `완료`. `보류`는 이유와 재개 조건이 필요하며 최종 완료로 간주하지 않는다. 기획 수치 변경은 본문과 콘텐츠 대장을 함께 갱신한다.
