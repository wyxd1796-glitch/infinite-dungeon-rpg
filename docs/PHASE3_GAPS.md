## 효과 구현 전 확정해야 할 의미

- EF016의 공격력 기반 지속 피해: 현재 화상처럼 부여 시 공격력 스냅샷을 쓸지 명시한다. 원본 수치 6은 6%로 단위를 선언하고 저장 필드를 설계한다.
- EF020~028: 명중·회피의 %p와 피해/MP 비용의 %를 분리한다. 최대 MP 감소는 현재 MP를 상한으로 자르되 만료로 현재 MP를 증가시키지 않는 기존 상한 원칙을 적용한다. 적용 시점은 원본 trigger와 실제 상시 능력치 판정의 차이를 명세해야 한다.
- EF031과 EF040은 모두 gold_up_pct지만 on_drop/on_reward가 다르다. 같은 보상에 이중 적용하지 않도록 보상 확정 시점과 중복 규칙을 정한다.
- EF037 보호막: on_damage가 매 피격마다 새 보호막을 생성한다는 뜻인지 정의가 부족하다. 승인된 스킬 보호막의 비누적 규칙과 구분하고 발동 횟수·순서·재생성 조건을 확정하기 전 비활성 상태로 둔다.
- EF038 반격: 기존 2차 피해의 재귀 반격·흡혈 금지 계약을 유지한다. on_hit의 주체가 공격자인지 피격자인지 대상 필드로 명시한다.
- EF039 생존: 한 전투/한 부여 중 어느 범위에서 1회인지 정의하고 사용 여부를 저장한다. 저장·불러오기로 다시 생존하지 않게 한다. 지속 피해·반사·동시 사망과의 우선순위를 테스트한다.

위 항목은 구현 완료가 아닌 보완 설계 요구다. 소스 문구로 빈 의미를 자동 추론해 채우지 않는다. 03-03에서 공통 계약, 03-04~05에서 효과별 실행 정의와 테스트로 확정한다.

## 유지할 불변식

1. 원본 SHA-256과 1,305개 ID·이름 보존. 기존 260개 활성 ID 및 phase2 28개 출처 연결 보존.
2. 승인된 8개 스킬·20개 이벤트는 원본 override로 덮어쓰지 않는다. 기존 스킬 5개의 초기 레벨과 투자도 유지한다.
3. 진행 중 전투의 적·패턴·장비 굴림·이벤트 확정 결과는 재생성하지 않는다. 신규 규칙 적용 시점을 저장 이전 계약으로 검증한다.
4. 미지원 참조가 원본에 존재한다는 것과 게임에서 사용할 수 있다는 것을 구분한다. 감사에서 찾은 실행 미연결 참조 845건은 참조 발생 횟수이며 서로 다른 콘텐츠 845개라는 뜻이 아니다.
5. 사용 목록에는 보유 항목만 표시하고, 학습/구매/도감은 별도 경로로 유지한다.
