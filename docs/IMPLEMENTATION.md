# 기획 분석과 구현 대응

> 1.0 버전 기록입니다. 현재 1.1 콘텐츠/경제/저장 규칙은 [PHASE1.md](PHASE1.md)가 우선합니다.

기준: `게임 기획 통합 상세명세서.pdf` v1.1(22쪽), `UI 디자인 통합 상세 명세서.pdf` v4.1(21쪽).

## 적용 우선순위

게임 공식은 게임 명세, UI 외형은 UI v4.1을 따릅니다. 예시 레벨·골드·장비를 실제 시작 상태로 사용하지 않습니다. 초기 스탯 대비 증가분만 적용하므로 HP 100 / MP 30 / 공격력 15 / 방어력 5로 시작합니다. 업적은 UI 예시의 30개 대신 조건이 확정된 7개입니다.

후속 사용자 요청으로 이벤트 상황 설명 및 상점 상품 설명은 제목 아래의 병합 셀에 전문을 줄바꿈 표시하며 이 셀만 높이를 유동적으로 적용합니다. 일반 속성 행은 25px을 유지합니다. 첫 선택기 오른쪽에는 기록·설정·거점 바로가기를, 제목 표시줄에는 ON 색상으로 구분되는 핀 버튼을 사용합니다. 상점 장비의 기존 무작위 생성 규칙은 유지하고 구매 전에 가능한 기본 능력치 범위를 안내합니다.

## 미확정 수치에 적용한 구현 가정

다음은 PDF에서 확정하지 않은 부분에 대한 **초기 플레이용 가정**이며 원문 확정값이 아닙니다. `content/base/balance.json`과 각 콘텐츠 JSON에서 조정할 수 있습니다.

| 항목 | 적용값 |
|---|---|
| 최초 소지품 | HP 물약 3개, MP 물약 1개, 초기 장비 없음 |
| 최초 스킬 | 액티브·패시브 모두 1레벨. 패시브 소수 보너스 적용 후 내림하여 초기 공격력/방어력은 15/5 유지 |
| 능력치 | 초기값 대비 투자 증가분 사용. 민첩·행운 기본값에도 회피/치명 0.2%p 적용, 상한 각각 75% |
| 강화비 | 장비 레벨 × 다음 강화 단계 × 20 G, 강화석 1 + floor((다음 단계−1)/3) |
| 회복비 | HP: 레벨×5 G, MP: 레벨×3 G. 이미 가득 찬 자원은 비용에서 제외 |
| 사망 복귀 | HP 최대치의 30%로 복귀, 일시 상태 해제. MP는 현재값 유지 |
| 물약 | HP 50 회복/30 G, MP 30 회복/40 G, 판매는 구매가의 절반 |
| 강화석 | 상점 40 G, 보스 층별 최초 처치 3개 |
| 보관함 확장 | 최초 1,000 G, 확장할 때마다 1,000 G 증가 |
| 상점 장비 | 70 + 최고 도달 층×10 G. 구매 시 현재 층 기준 랜덤 장비 생성 |
| 장비 판매 | 레벨×등급순번(1~5)×10 + 강화단계×5 G |
| 가방 용량 | 장비 1개당 1칸, 소비품·재료는 종류별 1칸. 착용 장비는 가방에서 분리 |
| 가방이 가득 찼을 때 | 구매/해제/꺼내기 거절. 드롭 장비는 판매가로 자동 환전, 새 종류 중첩 아이템은 획득 실패 로그 |
| 행운 | 5를 초과한 행운마다 희귀 이상 가중치 1% 증가 후 전체 정규화 |
| 몬스터 레벨 | 해당 층수. 몬스터 기본 수치는 monsters.json에서 지정 |
| 명중 | 공격 명중률−대상 회피율, 최소 5%. 적 기본 명중 95% |
| 치명타 | 방어 차감 후 피해에 1.5배 후 내림 |
| 스킬 성장 | 강타 +10%p/레벨, 회복 +5%p/레벨, 연속 베기 각 타격 +5%p/레벨 |

| 이벤트 | 동일 출현 가중치, 분기 있는 선택지는 성공70/실패30, 비용/보상/지속시간은 events.json |

## 확장안과 남은 검증 경계

게임 명세 18~29장은 향후 확장 설계입니다. 현재는 기본 콘텐츠와 작동하는 JSON 팩 로더를 구현했습니다. 제안된 지하 수로/심연 성채 팩, 추가 직업, 별도 던전 구역/드롭 테이블/상점 테이블 스키마, 임의 override, 구버전 간 순차 마이그레이션은 이번 최초 버전에 포함하지 않았습니다. 저장 스키마는 1이며 미래 버전 저장은 거절하고 원본을 유지합니다. 새 필드는 기본값으로 보완합니다.

소비품·재료의 원형을 제거하면 저장 수량은 보존되지만 제거된 정의의 거래/효과를 실행하지 않습니다. 미확인 장비는 표시와 보관을 유지하며 원형 팩을 복구하면 다시 사용할 수 있습니다.

기본 창과 전투·이벤트 및 확대 창은 Qt 실제 렌더링 이미지로 확인했습니다. 자동 테스트에서 고정 행 높이와 가로 스크롤 없음, 화면 전환 무턴, 선택 무소비, 실제 마우스 값 클릭을 검증했습니다. 실제 Windows 다중 모니터 이동, 작업표시줄 복원, 125%/150% 배율은 별도 수동 검수 항목입니다.

## 검증 결과

검증 커맨드와 시뮬레이션 결과는 README 및 `artifacts/simulation.json`을 참조합니다. 고층 수치 생성은 10,000층까지 검사했으나 이것이 무한 정수 연산의 수학적 보장이나 최종 난이도 승인을 의미하지는 않습니다. 3,000단계 진행으로 305층에 도달한 결과는 후반 성장 속도가 빠를 수 있음을 보여 줍니다. PDF의 지정 공식을 바꾸지 않았으며 실사용 밸런스 조정 대상으로 남깁니다.
