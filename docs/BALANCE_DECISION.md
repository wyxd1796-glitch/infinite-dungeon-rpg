# 2단계 수치 결정과 3단계 입력

2026-10-17 · 적용 프로필 `1.2.0-policy1` · 게임 1.2.0 / 저장 스키마 3 유지.

## 결정 범위

이번 결정은 **자동 전투 정책의 출시 기본값과 현재 전투 수치의 보존**이다. 전체 층의 목표 난이도를 달성했다는 승인은 아니다. 초기 통제 표본과 장기 진행의 차이를 근거로 적 수치 일괄 변경을 하지 않고, 성장 경로 문제를 3단계 설계 입력으로 넘긴다.

| 항목 | 확정 값 / 처리 | 근거 |
|---|---|---|
| 기본 회복 정책 | 물약 우선 | 기존 저장의 행동·난수 호환. 다른 정책이 모든 준비·빌드에서 우세하다는 근거 없음 |
| 기본 공격 MP 예약 | 0 | MP 여유가 적은 초기 캐릭터의 공격을 강제로 막지 않음. 사용자는 0~999 설정 가능 |
| 회복 스킬 조건 | 기존 회복 HP 70% 이하, 응급 치료 HP 50% 이하 또는 제거 가능 상태 | 승인된 스킬 설계 유지. 단순 사용 횟수 증가를 위해 발동 조건을 확대하지 않음 |
| 위험 중단 | 기존 사용자 설정·경계값 이하 판정 유지 | 효율 정책이나 정화가 안전 중단을 우회하지 않음 |
| HP 물약 기준 | 기존 30/50/70% 선택 유지 | 스킬 정책과 별도 사용자 설정. 실험용 준비 스크립트가 기본값을 바꾸지 않음 |
| 스킬 MP·배율·쿨다운 | 현재 1.2.0 값 유지 | 자원·턴·상태 상호작용 회귀 검증 완료. 장비 준비 편차가 커 단독 조정 근거 부족 |
| 피해 상한·철벽 별도 감소 | 현재 프로필 유지 | [계산 순서](BALANCE_SPEC.md) 및 이전 저장 효과 보존 |
| 적·장비·물약·드롭 가격과 수치 | 이번에는 유지 | 고층·장비·보급을 함께 바꾸는 3단계 범위에서 비교할 것 |

## 측정 근거

- [초기 정책 비교](AUTO_POLICY_REPORT.md): 20시드, 통제 전투 5,400회, 초기 진행 18,000결정. 통제 보스 승률 100%로 목표 60~85%를 초과했으나, 해당 준비 장비의 경제적 도달 가능성을 보장하지 않는 표본이었다.
- [장기 진행](LONG_TERM_REPORT.md): 실제 시작 재화와 획득 보상으로 진행하는 기존 준비 및 자금 기반 준비를 분리한다. 골드 보존·명령 비용·귀환·장비 교체·사망층·스킬 사용을 기록한다. 상세 결과와 한계는 해당 보고서를 따른다.
- 계측 도입 전후 동일 시드의 결과 일치, 준비 시 자원 한도, 정상 귀환과 사망의 구분을 테스트한다. 순골드 변화는 시작 골드와 실제 잔액으로 대조한다.

## 목표 미달을 처리하는 원칙

장기 측정 결과, 기존 준비 9조합의 최고층 중앙값은 모두 40층이었다. 자금 기반 준비의 중앙값은 공격 50.5층, 방어 40층, 회복 40.5층이었다. 준비를 바꿔 일부 등반 범위가 넓어져도 정체가 전부 해소되지는 않았다.

귀환 사이 층 이동 중앙값은 기존 준비 1층, 자금 기반 준비 0~1층으로 목표 3~8층보다 짧았다. 다만 이 측정은 사망 여정을 제외한 이동 횟수이며 HP 60% 미만에서 귀환하는 시험 규칙에 의존한다. 따라서 이를 물약 회복량만의 문제로 단정하지 않는다.

자금 기반 준비의 강화 지출은 빌드별 20시드 합계 약 103만~110만 G였다. 교체는 기존 준비에서 빌드·정책별 811~870회, 자금 기반 준비에서 556~570회였다. 새 장비를 반복 강화하는 비용과 이미 강화한 장비 대비 교체 가치가 함께 작용하므로, 3단계에서 장비 기본 성장·강화 후 비교·보급 비용을 함께 검증한다. 강화가 교체 감소의 유일한 원인이라고 해석하지 않는다.

회복 조합의 기존 준비에서는 회복 스킬 우선의 물약 소비가 물약 우선보다 적었지만(5,689 대 6,218개), 사망은 더 많았다(2,415 대 2,340회). 다른 조합에서도 단일 정책의 일관된 우세가 나타나지 않았다. 기본값을 바꾸지 않고 사용자 선택을 유지하는 근거다. 장기 실험의 모든 240표본에서 자금 흐름 검산을 통과했다.

일반전/정예/보스 전투 길이, 60~85% 준비된 보스 승률, 3~8층 보급 주기, 10층마다 의미 있는 장비 갱신은 설계 목표로 유지한다. 이번 자동 운용에 의한 교체 횟수와 이동 층수는 사람의 전략적 선택 가치·최적 보급 주기와 같지 않다. 높은 승률의 통제 준비와 반복 사망하는 자연 진행 중 한쪽만 보고 적을 강화하거나 약화하지 않는다.

02-11은 목표 달성 체크가 아니라 **목표와 실측 차이를 기록하고 현재 버전에 적용할 수치를 결정하는 작업**으로 종료한다. 장기 목표 미달은 숨기지 않고 다음 콘텐츠 단계의 완료 기준으로 유지한다. 1단계의 실제 Windows 배율·다중 모니터 검수도 별개로 남는다.

## 다음 구현 순서

1. 03-01: 원본/현재 활성 범위와 효과·성장 산식 충돌을 대조한다. 원본 문구로 효과를 추측하지 않고 미지원 연산자를 명시한다.
2. 03-02~03: 명시적 활성 ID·지역 선택과 공통 효과 시점을 정리한다. 이전 장비·적 인스턴스는 재굴림하지 않는다.
3. 방어구 HP/DEF, 마력 MP, 강화 비용 대비 실제 교체 가치, 물약 해금/회복량/가격을 같은 준비 예산에서 설계한다. 교체 직후 다시 강화하는 비용과 재료 소비를 함께 측정한다.
4. 100→101층뿐 아니라 인접 **일반층끼리** 비교하고, 보스→일반 난이도 차이는 별도 표본으로 처리한다.
5. 수치 변경 후보는 새 프로필에 기록하고 동일 시드·초기 예산으로 비교한다. 이전 원자료를 덮어쓰지 않는다. 보유 목록·학습 보기·저장 이전 검증을 다시 적용한다.

재현용 스크립트와 결과는 개발 도구다. 실사용 저장에 무료 재화나 장비를 주입하지 않는다. GitHub 업로드는 별도 요청 시 진행한다.
