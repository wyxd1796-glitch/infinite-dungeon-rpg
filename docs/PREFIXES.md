# 03-11 접두어 50종

2026-10-19. `phase3-prefix-1.0.0`. 원본은 수정하지 않고 `content/catalogue/prefixes.json`에 PFX001~050의 명시적 실행 연산자·수치를 기록했다. 원본 설명은 실행하지 않는다. 카탈로그 765개, phase2를 포함한 출처 연결 793개다.

## 선택과 호환

- 일반 적은 기존 18% 확률로 1개, 정예는 기존 1~2개, 보스는 0개다. 동일 범주는 최대 1개이고 원본 가중치를 사용한다.
- 기존 20개는 1층부터 유지한다. 신규 PFX021~026은 101층, 027~032는 131층, 033~038은 161층, 039~044는 191층, 045~050은 221층부터 선택한다. 해금은 절대층이며 원형 순환 이후 잠기지 않는다.
- 기존 1~100층 선택/상태/난수 재현과 기존 전투 스냅샷을 유지한다. 신규 접두어는 새 조우에만 부여한다. 저장을 읽으며 접두어 능력치를 재계산하지 않는다.
- 배율은 생성 시 기본 수치에 반영하고, 반사·재생·저항·타격 발동·처형·생존·드롭은 `enemy.prefix_runtime.version=1`에 저장한다. 스키마 3의 선택적 전투 필드이며 없는 기존 저장은 기존 처리를 따른다. 잘못된 연산자/대상/참조/수치/저장 버전·범주 중복을 거절한다.

## 신규 효과 계약

| ID | 실행 효과 |
|---|---|
| PFX021~025 | 공격 +17%, 치명 +7%p, 공격 +22%, 공격 +27%/방어 -8%, 공격 +14%/흡혈 +3% |
| PFX026 | 공격 직전 대상 HP가 최대 HP 30% 이하이면 직접 공격 배율 ×1.22. 지속·반사 피해 제외 |
| PFX027~032 | 방어 +18%, 방어 +24%, 반사 6%, 방어 +28%/회피 -3%p, 직접 피해 감소 12%, HP +15%/방어 +8% |
| PFX033~038 | HP +18%, 턴 시작 HP 2% 재생, 직접 처치 직후 HP 5% 회복, HP +25%/회피 -5%p, 상태 저항 +15%p, 전투 1회 HP 1 생존 |
| PFX039~044 | 빙결 10%, 감전 15%, 부식 12%, 암흑 15%, 혼란 10%, 저주 20% |
| PFX045~050 | 장비 드롭 확률 ×1.15, 골드 ×1.25, 경험치 ×1.25, 경험치 ×1.35/공격 ×1.05, 기본 재료 확률 ×1.25, 이번 처치 장비 희귀 이상 확률 +4%p |

기존 20개도 같은 선언형 적용기로 이동했으며 수치·순서를 보존한다. 반사·흡혈·저항·감소·재생은 공통 피해/회복 처리와 기존 상한을 사용한다. 공격·방어·HP 배율은 내림하며 보상 배율은 보상 확정에서 내림한다.

타격 상태효과는 적의 주 공격이 실제 HP 피해를 낸 뒤 판정한다. 빗나감·보호막 완전 흡수·사망 시 발동하지 않는다. 상태 저항, 행동불가, 빙결 면역 기간, 중첩/지속시간은 기존 공통 효과 규칙을 따른다. 추가 공격/반격에서 발동 효과를 재귀 실행하지 않는다.

PFX038은 직접·반사·지속 피해의 치명 피해에서 공통 생존 플래그를 사용한다. EF039와 함께 있어도 두 번 생존하지 않고, EF039가 활성화돼 있으면 기존 1% HP 생존값을 우선한다. 재접속으로 횟수가 복구되지 않는다. UI에 사용 완료를 표시한다.

PFX035는 현재 단일 플레이어 전투에서 플레이어 직접 처치 직후, 패배 처리 전에 적 HP를 회복한다. 이 효과가 플레이어의 부활·추가 전투·새 보상을 생성하지 않는다. 적 지속 피해나 반사로 인한 처치에는 적용하지 않는 이번 실행 범위를 화면에 명시했다.

드롭의 +15%/+25%는 상대 배율로 확정했다. 예: 일반 장비 15%→17.25%, 기본 재료 20%→25%. 최종 확률은 100% 상한이며 정예 드롭 보장·추가 재료 추첨·보스 확정 재료는 기존 규칙을 유지한다. PFX050은 희귀/영웅/전설 가중치 합에 +4%p를 분배하는 기존 계산기를 사용한다. 보너스는 해당 처치 장비에만 전달하며 탐험 보너스로 저장하거나 이후 보상에 누적하지 않는다. 가방 초과는 기존 획득 대기다.
