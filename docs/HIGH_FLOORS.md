# 03-06~09 — 고층 콘텐츠와 순환 규칙

2026-10-18. 카탈로그 `phase3-depth-1.0.0`, 고층 전투/장비 생성 규칙 1. 게임 표시 버전 1.2.0과 저장 스키마 3은 유지한다. 원본 JSON과 실행 관련 수정은 보존했다.

## 연결 범위

101~200, 201~300, 301~400층의 명시적 출현 풀과 보스, 장비, 소비품, 환경을 연결했다. 활성 카탈로그는 735개: 몬스터 150, 보스 40, 접두어 20, 장비 330, 옵션 30, 소비품 30, 재료 60, 환경 30, 층 유형 5, 효과 40. phase2의 출처 연결 28개를 더한 총 출처 연결은 763개다.

- 몬스터와 보스 원형은 400층마다 순환한다. 몬스터는 원본 최소/최대층과 명시적 지역 풀의 교집합에서 선택한다. BOS001~040은 10층 간격으로 배치하며, 410층은 BOS001을 절대 410층 능력치로 생성한다.
- 환경 30개는 독립적으로 300층마다 순환한다. 따라서 301층 ENV001, 401층 ENV011, 800층 ENV020, 1,000/10,000층 ENV010이다.
- 고층 일반 몬스터는 현재 환경 주 종족에 70%, 나머지 종족에 30%를 배분하고 각 집단 내부는 원본 가중치를 사용한다. 한 집단이 비면 전체 원본 가중치로 추첨한다. 1~100층은 기존 가중치×3을 그대로 사용한다.
- 고층 환경 효과는 새 전투 진입 시 10% 확률로 1회 적용한다. EF016~028은 플레이어 약화, EF029~040은 적 강화다. 효과 자체의 상태 저항·기간·상한 계약을 따른다. 같은 저장을 다시 불러와 적용하지 않는다.

## 절대층 성장

F는 절대층, L은 굴림 장비 레벨이다. 정수 능력치는 마지막에 내림한다. 수치는 원본 변경이 아닌 `content/catalogue/high_floors.json`의 실행 설계값이다.

일반 적은 기존 100층 일반 풀의 정확한 가중 평균을 기준으로 HP `(F/100)^1.15`, ATK/DEF `(F/100)^0.8`을 적용한다. 원형 능력치를 해당 풀의 가중 평균으로 나눈 역할 계수를 0.8~1.2로 제한하고, 다시 가중 평균 1로 정규화한다. 환경/원형 순환에 따른 평균 급락을 막으면서 원형별 차이를 남긴다. 이 기준값에 정예 HP×2·ATK×1.4, 재앙 HP/ATK×1.2, 접두어 보정을 기존 순서로 적용한다. 고층 환경 위험%를 중복 곱하지 않는다.

고층 보스는 기존 100층 보스의 HP 9,420 / ATK 433 / DEF 80을 기준으로 같은 지수를 사용한다. 원본 보스의 능력치 배율은 출처 데이터로 남기고 신규 고층 생성에서는 추가로 곱하지 않는다. 단계 전환 비율·공격 배율·패턴·효과·특수 행동은 각 보스 정의를 따른다. 400→410층에도 같은 절대층 식을 사용한다.

고층 골드/경험치는 기존 `(10+3F)` / `(25+8F)`와 적 종류 배율에 고정 1.27을 곱한다. 재앙·장비·효과의 보상 보정과 상한은 유지한다. 환경 순환으로 보상 배율이 초기화되지 않는다.

## 장비·물약·재료

EQ001~090과 보유 중인 모든 장비의 굴림값은 유지한다. EQ091~330의 신규 생성에는 원형 기본값에 ATK `2.5L`, DEF `1.2L`, HP `6L`, MP `2L`을 추가한다. ATK에는 기존 `floor(3+1.5L)`도 유지하므로 총 레벨 기울기는 4다. % 능력치는 이 선형 가산을 하지 않는다. 신규 고층 장비는 101층에서 99레벨로 굴려도 해당 식을 사용한다.

일반 고층 드롭 풀은 `min_floor >= max(101,min(400,F)-60)`인 해금 원형이다. 순환 후에도 최근 고층 원형을 유지하고 굴림 레벨은 절대층을 따른다. 상점에는 최고 도달층까지 해금된 원형을 표시한다. 장비 옵션은 원본 범주 중 현재 지원하는 OPT001~030의 슬롯/범주와 일치하는 항목만 사용하며, 원래 풀은 source_option_pool로 남긴다. OPT031~100 확대는 03-15다.

| 물약 | 해금층 | 최대 HP·MP 각각 회복 | 구매 G |
|---|---:|---:|---:|
| CON021 | 101 | 20% | 75 |
| CON022 | 151 | 25% | 150 |
| CON023 | 201 | 30% | 225 |
| CON024 | 301 | 35% | 300 |
| CON025 | 401 | 40% | 375 |

회복 비율·해금은 신규 실행 정의이고 가격은 원본을 유지했다. 효과/경제 최종 조정은 03-16/23이다. CON036~040은 원본 dispel_targets에 명시된 상태만 제거한다. 소비품 사용의 행동 소모·적 반격·사용 가능 상황은 기존 공통 처리에 연결했다. CON026~035·041~050은 의존 기능이 없어 활성화하지 않았다.

재료 MAT001~060은 몬스터 드롭 및 추가 재료 보상에서 얻고 거점에 판매할 수 있다. 고층 보스는 연결된 원형 재료 2개를 추가 지급하며 기존 최초 강화석·결정 보상도 유지한다. 가방 초과는 획득 대기로 보존한다. 모든 재료의 현행 소비처는 판매 또는 기존 강화 대체이며, 신규 제작·정제의 완성을 뜻하지 않는다. 03-17/04-07에서 전용 소비처를 추가한다.

## 보스 행동 계약

원본 패턴의 공격·방어·특수공격 외에 강공격(ATK 150%, 명중×0.85), 회복(최대 HP 4%), 상태효과 행동(60% 확률)을 지원한다. 강화 효과는 보스 자신, 약화는 플레이어에게 적용한다. 침묵은 특수공격·회복·상태효과 행동을 일반 공격으로 바꾼다. 강공격은 물리 행동으로 유지한다.

새 보스의 특수 행동은 특수공격 시 발동한다. 특수공격이 없는 패턴은 강공격 시 발동한다.

| 원본 기믹 | 명시적 실행 효과 | 대응 |
|---|---|---|
| 보호막 파괴 | 첫 공격 직전 플레이어 보호막 제거 | 해당 순서 전 보호막 사용을 피하고 방어/회복 |
| 단일 강타 | ATK 200% 단일 공격 | 방어·피해 감소 |
| 연속 공격 | 첫 공격 뒤 ATK 70% 추가 공격 | 두 공격을 견딜 HP 확보 |
| 특수 소환 | 최대 HP 8% 보호막, 발동 행동 포함 적 행동 2회 ATK 25% 보조 공격 | 행동불가·보호막 소진 후 집중 공격 |
| 회복 억제 | 이후 플레이어 행동 2회 HP 회복 50% 감소, MP는 유지 | 미리 회복하거나 지속시간 동안 방어 |
| 추가 상태이상 | 30% 확률 취약, 받는 피해 15% 증가 | 정화·상태 저항 |

소환체는 현재 단일 적 구조에서 보호막·보조 공격으로 명시 구현했다. 별도 공격 대상이나 추가 처치 보상을 만들지 않는다. 보호막은 현재값/신규값 중 큰 값으로 갱신한다. 소환 지원 횟수는 적 행동불가 동안 줄지 않는다. 회복 억제는 플레이어 행동불가로 소비한 행동도 센다. 추가 공격 전에 사망을 확정하므로 죽은 적/플레이어의 후속 공격·중복 보상이 발생하지 않는다.

## 저장과 화면

신규 전투의 enemy에 depth_rules_version=1, environment_snapshot, reward_factor를 보존하고 보스에는 mechanic/summon_turns/healing_suppression/suppression_at을 보존한다. 신규 장비에는 generation_rules_version=1을 남긴다. 기존 스키마 3에 선택적 버전 필드를 추가했으며 없으면 기존 경로를 사용한다. 기존 전투를 생성하거나 기존 장비 능력치를 다시 굴리는 이전 작업은 없다. 구버전 프로그램으로 신규 고층 저장을 읽는 것은 지원하지 않는다.

기존 고층 전투에는 적 스냅샷·원래 100층 환경 순환·기존 장비 보상 풀·재료 추가 풀을 보존한다. 종료 후 새 전투부터 고층 규칙을 적용한다. RNG·대기시간·진행도·획득 대기·확정 이벤트는 기존 저장 계약을 따른다. 같은 결과를 불러와 다시 지급하지 않는다.

던전 탐험은 현재 원형 구간/독립 환경 구간/다음 보스, 전투는 패턴 순서/상태 설명/특수 행동과 잔여시간을 표시한다. 기존 8개 메인·22개 하위 화면을 사용한다. 소지품·사용 스킬에는 실제 보유/학습 항목만 표시하는 정책을 유지한다. 구매·해금 목록은 별도 획득 경로다.
